# Relatório com interesse em economia e finanças

Este relatório integra todas as atividades desenvolvidas relacionado a exploração das simulações de preços utilizando os modelos de ordem não fracionária (ARIMA) e de ordem fracionária (ARFIMA). Devido ao aumento de criptomoedas no mercado financeiro, o mesmo foi objeto de estudo para obter as previsões futuras da dinâmica de preços.
